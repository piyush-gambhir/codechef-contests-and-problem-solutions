# CodeChef Contests and Problem Solutions

Solutions to CodeChef contests and individual practice problems.

## Layout

- **`Contests/`** — solutions grouped by contest:
  - Long Challenges (Jan / Feb / etc.)
  - Cook-Offs (e.g. February Cook-Off 2023)
  - Lunchtime contests
  - Weekly Contests
  - Themed events — Insomnia Coding Challenge, NCU Hacks 1.0
- **`Problems/`** — standalone practice-problem solutions

## Languages

Primarily C++ and Python, with Java where preferred.
